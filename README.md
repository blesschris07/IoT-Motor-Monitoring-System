# IoT-Based Smart Industrial Motor Monitoring System

## 1. Project Overview
The Smart Industrial IoT Motor Monitoring System is designed to monitor industrial motor health and operating conditions using sensors and IoT technology.

## 2. Controller
- Arduino UNO
- ESP8266 Wi-Fi Module

## 3. Sensors
- MPU6050 – Vibration Monitoring
- LM35 – Temperature Monitoring
- ACS712 – Current Monitoring
- Hall Effect Sensor – RPM Measurement

## 4. Output Devices
- 16x2 I2C LCD Display
- Buzzer
- Green, Yellow and Red LEDs
- Relay Module

## 5. Main Features
- Real-time motor monitoring
- Temperature measurement
- Vibration detection
- Current consumption monitoring
- RPM measurement
- Abnormal condition alerts
- Motor protection using relay control

## 6. Working Principle
Sensors collect motor operating parameters and send the readings to the Arduino UNO. The controller processes the readings and displays information on the LCD. When abnormal conditions are detected, alerts are activated and relay-based motor protection can be implemented.
